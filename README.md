# 01Academy AI Kids — Детский веб-сайт в стиле Duolingo 🚀🦉

Яркий, интерактивный и геймифицированный веб-сайт для детей и родителей, посвящённый курсам искусственного интеллекта от **01Academy** (Ташкент, ул. Тараса Шевченко, 20).

## 🌟 Особенности проекта

- **Фирменный стиль Duolingo**:
  - Палитра: ярко-зеленый (`#58cc02`), объемные 3D-кнопки с эффектом продавливания, чистый белый фон и яркие игровые акценты.
  - Маскот «Ай-Бот»: анимированный робот-помощник с живыми эмоциями, морганием глаз и диалоговыми облачками с полезными подсказками.
  - Игровая панель (Gamification Bar): очки опыта (XP ⭐), кристаллы (💎), ударный режим (🔥), жизни (❤️).
  - Аутентичные звуковые эффекты Duolingo (чистый Web Audio API: звонкий клик, 2-тональный колокольчик успеха, победный фанфар при прохождении квестов).
- **Официальный контент 01Academy (01academy.uz)**:
  - **AI Explorer (7–10 лет)**: 8 недель — рисование, комиксы, формулирование запросов (промптов) простыми словами.
  - **AI Creator (11–14 лет)**: 10 недель — сценарии, видео, фактчекинг и честное применение AI в учебе.
  - **AI Professional (15–18 лет)**: 12 недель — проектное мышление, исследование и защита стартап-проектов.
  - Реальные проекты учеников (Амир-Мирзо 10 лет, Асаль 7 лет и старшеклассники).
  - Информация о локации (Ташкент, ул. Тараса Шевченко, 20), формате (раз в неделю по выходным, 90 мин, мини-группы до 12 человек).
- **Интерактивные механики**:
  - **Тропа уровней (Roadmap)**: дорожка из уровней с кликабельными узлами и окнами описания миссий.
  - **Промпт-Лаборатория**: интерактивный генератор запросов для детей (выбор героя, стиля и действия с живым предпросмотром).
  - **Тест-квест**: 3 вопроса с салютом из конфетти и подбором курса.
  - **Форма записи**: мгновенное начисление +50 XP и генерация персонального именного «Сертификата исследователя AI».

## 🚀 Как запустить сайт

### Вариант 1: Просто открыть в браузере
Дважды кликните по файлу `index.html` или откройте его в Google Chrome, Safari или любом другом браузере:
```bash
open /Users/sheri/.gemini/antigravity/scratch/ai-kids-01academy/index.html
```

### Вариант 2: Локальный веб-сервер
В терминале:
```bash
cd /Users/sheri/.gemini/antigravity/scratch/ai-kids-01academy
python3 -m http.server 8088
# или
npm start
```
Затем перейдите по адресу: [http://localhost:8088](http://localhost:8088)
