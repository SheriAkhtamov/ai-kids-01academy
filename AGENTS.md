# Правила и инструкции для ИИ-агентов (AI Agents Guidelines)

## 🚨 Обязательное правило публикации изменений (Git Push Rule)

**ВСЕ новые изменения агент ОБЯЗАН сразу же отправлять на GitHub в ветку `main`.**

Каждый раз после внесения правок (создания, редактирования или удаления файлов):
1. Проверить статус изменений:
   ```bash
   git status
   ```
2. Зафиксировать изменения с осмысленным комментарием:
   ```bash
   git add -A
   git commit -m "Краткое описание сделанных изменений"
   ```
3. Немедленно отправить изменения на GitHub:
   ```bash
   git push origin main
   ```
4. Убедиться, что отправка прошла успешно (код возврата 0).
5. Никогда не завершать задачу, оставляя незакоммиченные или неотправленные в `origin/main` файлы.

## Архитектура проекта

- Проект представляет собой статический сайт (HTML, Tailwind CSS CDN, кастомный CSS `styles.css`, чистый JS `app.js`).
- Все пути к ассетам (`assets/...`) должны оставаться **относительными**, чтобы сайт корректно работал на GitHub Pages.
- При любых доработках сохранять интерактивность (трекинг взгляда крокодила, ротатор текста, плавная прокрутка, форма).
